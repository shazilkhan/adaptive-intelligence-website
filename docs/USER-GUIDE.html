3. Getting the code

3.1 Clone the repository (first time)

  1. Open a terminal (Command Prompt, PowerShell, or Terminal).
  2. Go to the folder where you want the project, e.g. cd Desktop
  3. Clone the repo: 
    git clone https://github.com/Adaptive-Admin-User/adaptive-intelligence.git "Adaptive Intelligence"
cd "Adaptive Intelligence"
  4. You should see folders like src, backend-new, public, package.json.

3.2 Get the latest code (already have the project)

cd "C:\Users\YOUR_USERNAME\OneDrive\Desktop\Adaptive Intelligence"
git pull origin main

Use your actual path and branch (e.g. main or master).

4. Frontend (website)

The frontend is the public site. Its code is in the root of the project (not inside backend-new).

4.1 Folder structure (what to edit)

Folder / fileWhat it’s for
src/pages/One file per page: index.js (home), about.js, contact.js, services.js, case-studies/, etc.
src/components/Reusable pieces: header, footer, forms, sections
src/styles/Global styles (e.g. index.scss)
src/data/Static data (e.g. menu items)
public/Static images, favicon (don’t go through build)

To change a page, open the file under src/pages/. To change header/footer, look in src/components/.

4.2 Run the frontend locally

  1. Open a terminal in the project root (where package.json and src are).
  2. Install dependencies (first time only): 
    yarn install
  3. Start the dev server: 
    yarn dev
  4. Open a browser at: http://localhost:3000
  5. To stop: press Ctrl + C in the terminal.

4.3 Build the frontend (test production build)

yarn build
yarn start

Then open http://localhost:3000. Same as what runs on Amplify.

4.4 Frontend environment variables

For local runs, create a file in the project root named .env.local (git-ignored). Example:

NEXT_PUBLIC_STRAPI_API_URL=https://admin.adaptiveintelligence.online

Production (Amplify): Set variables in Amplify Console → App settings → Environment variables. The build uses amplify.yml to write some into .env.production.

5. Backend (Strapi CMS)

The backend is Strapi. Its code is in backend-new.

5.1 Folder structure (what to edit)

Folder / fileWhat it’s for
backend-new/src/api/Content types and API (homepage, about-page, case-study, etc.)
backend-new/config/Database, plugins (S3 upload), server, middlewares
backend-new/src/admin/Admin panel branding (logo, theme in app.tsx)
backend-new/scripts/One-off scripts (e.g. update file URLs to S3)

Most content changes are done in Strapi Admin in the browser, not in code.

5.2 Run the backend locally

  1. Open a terminal and go into the backend folder: 
    cd "C:\Users\YOUR_USERNAME\OneDrive\Desktop\Adaptive Intelligence\backend-new"
  2. Install dependencies (first time only): 
    yarn install
  3. Copy env example and edit: 
    copy env.example .env
    Then open .env and set database etc. (see section 7).
  4. Start Strapi: 
    yarn develop
  5. Open: http://localhost:1337/admin
  6. Create admin user if first time; otherwise log in. Stop with Ctrl+C.

5.3 Strapi Admin (content only, no code)

  • URL (production): https://admin.adaptiveintelligence.online/admin
  • Edit homepage, about, services, case studies, team, settings, media library, forms. No code or deploy needed for content-only changes.

6. Deploying changes

6.1 Deploy the frontend (website)

The frontend deploys automatically when you push to the connected branch (e.g. main) on GitHub.

  1. In the project root: 
    git add .
git commit -m "Describe your change in a short line"
git push origin main
  2. In AWS Console → Amplify → your app. A new build starts. Wait until status is Succeeded.
  3. Live site updates at your main domain.

Changing frontend env vars: Amplify → your app → Environment variables → add/edit → then Redeploy.

6.2 Deploy the backend (Strapi)

Backend runs on AWS App Runner. You must build a Docker image, push to ECR, then deploy in App Runner.

Step 1 – Log in to ECR:

aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 066123827652.dkr.ecr.us-east-1.amazonaws.com

Step 2 – Build the image:

cd "C:\Users\YOUR_USERNAME\OneDrive\Desktop\Adaptive Intelligence\backend-new"
docker build -t adaptive-strapi .

Step 3 – Tag for ECR:

docker tag adaptive-strapi:latest 066123827652.dkr.ecr.us-east-1.amazonaws.com/adaptive-strapi:latest

Step 4 – Push to ECR:

docker push 066123827652.dkr.ecr.us-east-1.amazonaws.com/adaptive-strapi:latest

Step 5 – Deploy in App Runner: AWS Console → App Runner → your service (e.g. strapi-adaptive) → click Deploy. Wait until status is Running.

Changing backend env vars: App Runner → your service → Configuration → Edit → Runtime environment variables → add/edit → Save and deploy.

6.3 Fix existing media URLs (S3) in the database

If you see 404 for existing images in Strapi or on the site:

  1. Ensure backend-new/.env.upload-migration or .env has the same database and S3 settings as production.
  2. From backend-new folder: 
    node scripts/update-file-urls-to-s3.mjs
  3. You should see: Updated N row(s) (main url). and Updated N row(s) (formats/thumbnails).
  4. No redeploy needed; refresh admin or site.

All set in App Runner → Configuration → Runtime environment variables. Reference list in backend-new/.env.apprunner (do not commit). Main ones: HOST, PORT, NODE_ENV, APP_KEYS, ADMIN_JWT_SECRET, API_TOKEN_SALT, TRANSFER_TOKEN_SALT, ENCRYPTION_KEY, DATABASE_*, AWS_*, CDN_URL, NODE_TLS_REJECT_UNAUTHORIZED.

Never commit real passwords or keys to the repository.

9. Troubleshooting

Frontend

  • “APOLLO_API_KEY is missing” or forms don’t work: Add required vars in Amplify (APOLLO_*, NEXT_PUBLIC_STRAPI_API_URL, REVALIDATION_SECRET) and ensure amplify.yml writes them to .env.production. Redeploy.
  • Site shows old content: Confirm NEXT_PUBLIC_STRAPI_API_URL in Amplify points to the correct Strapi URL. Redeploy.
  • Build fails on Amplify: Check build logs; fix code and push again.

Backend (Strapi on App Runner)

  • Strapi won’t start / “Timeout acquiring a connection”: Check RDS security group allows port 5432; check App Runner env vars (DATABASE_*, NODE_TLS_REJECT_UNAUTHORIZED=0 if needed).
  • “Access Denied” or “PutObjectAcl” on upload: IAM user (e.g. strapi-upload) needs s3:PutObjectAcl (and PutObject, GetObject, DeleteObject) on the S3 bucket.
  • Images/thumbnails 404: Run node scripts/update-file-urls-to-s3.mjs; ensure S3 bucket policy allows public GetObject; redeploy if you changed middleware.
  • JSON parse error on upload: Ensure latest code (with upload middleware) is in the Docker image and you’ve pushed and redeployed.

Custom domain (admin.adaptiveintelligence.online)

  • “Pending certificate DNS validation”: Add the exact CNAME records from App Runner in Route 53. Wait up to 24–48 hours.
  • Linking the admin subdomain does not change the main domain or frontend.
